FocusShield policy pages

Files:
- privacy-policy.html
- terms-of-service.html

Publishing with GitHub Pages:
1. Create a public GitHub repository, for example: focusshield-legal.
2. Upload both HTML files to the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the site.

The URLs will generally be:
https:joseph-1015.github.io/focusshield-legal/privacy-policy.html
https:joseph-1015.github.io/focusshield-legal/terms-of-service.html

Replace YOUR-GITHUB-USERNAME with your actual GitHub username. Do not enter these example URLs in the app or Play Console until GitHub Pages is live and the pages open publicly.

Before publishing:
- Review both documents for accuracy.
- Confirm the privacy statements match the release APK and all bundled libraries.
- Consider legal review, especially the governing-law and liability clauses.
